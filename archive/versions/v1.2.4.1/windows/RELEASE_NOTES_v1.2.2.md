# VoiceSpreader v1.2.2

## 双端麦克风同步

- Windows 与 Android 的麦克风启停统一由 Windows 会话协调器收敛，手机和电脑都可以发起请求。
- 每个请求都带有单调递增的命令序号；Windows 会丢弃迟到的旧回包，Android 会忽略重复命令。
- 手机停止时不再先修改一份状态、再异步反向修改另一份状态，避免启停竞态和快速抖动。
- 手机请求、Windows 命令、Android 实际采集状态分为三类消息，状态回报不会再次触发路由命令。
- 保留对旧版 Android 客户端的兼容路径；新版客户端会在握手中声明序号同步能力。

## 验证

- Windows Release 构建通过。
- Android Debug 构建、单元测试和 lint 通过。
- 覆盖手机主动停止、电脑主动停止、重复命令和迟到状态回包的协议测试。
