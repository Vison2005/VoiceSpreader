# VoiceSpreader Windows v1.2.3

## 设备互联管理

- 持久化 Windows 配对会话身份，应用重启后已保存的 Android 设备仍可通过会话 ID 自动定位新的端口。
- 首次配对成功后，Android 端保存电脑信息并提供一键连接、移除设备操作。
- 直连失败时自动通过局域网定位服务刷新电脑 IP 与端口，无需重新扫描二维码。
- Windows 断线或重启后广播稳定会话，已保存的 Android 设备可在前台服务中静默恢复。
- Android 服务保持单一活动电脑连接，切换连接时会先结束旧链路，避免同一手机并发占用。

## 兼容性

- 与 Android v1.2.3 配套使用。
- 保留二维码和六位配对码作为首次配对及凭据重置入口。
