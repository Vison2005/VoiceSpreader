# VoiceSpreader Windows v1.2.4.0

## 手机增强控制

- 新增 protocol 3 能力协商，支持手机触摸板指针、鼠标按键、滚轮和白名单快捷键。
- 新增电脑端 `.exe` 应用白名单：在“设备互联”中添加应用后，手机触摸板会同步显示一键启动入口。
- 新增独立文件通道：手机文件拖入应用内共享区后，电脑端流式接收并校验 SHA-256，避免占用音频通道。
- 新增电脑请求手机扫码（相机/相册）和拍照传输入口；仅自动打开 `http`/`https` 链接。
- 新增“极暗”主题，触摸板可在手机端使用纯黑背景，避免调用系统亮度 API。
- 手机断线或输入取消时自动释放 Windows 鼠标键和键盘键，降低异常状态残留风险。

## 兼容性

- 保留 protocol 1/2 和原有音频帧，旧版 Android 仍可进行音频互联。
- protocol 3 功能控制连接可与旧版音频连接并行，输入/文件不会阻塞音频传输。
