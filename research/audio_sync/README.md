# 多设备音频同步研究资料

本目录存放多设备音频同步的论文、方法与 Windows 实现记录。

## 文档

- [01 多设备音频同步方案综述](./01_多设备音频同步方案综述.md)：探针以外的数学、物理和 Windows 计算机实现方法。
- [02 傅里叶变换与音频同步](./02_傅里叶变换与音频同步.md)：DFT 相位斜率、GCC-PHAT、STFT 线性相位漂移、SRO 估计和频域校正。
- [03 傅里叶同步论文与工程实现](./03_傅里叶同步论文与工程实现.md)：筛选有明确数学模型、补偿算法、实时块处理或实验结果的论文，并映射到 Windows 实现。

## 使用说明

文档中的论文题目、DOI、arXiv、会议页面和微软官方 API 文档均保留为链接，便于后续按“论文原理—仿真—Windows 实测”继续扩展。傅里叶方法只能从可观测的共同音频估计相对延迟或采样率偏差；设备内部 DAC、蓝牙编解码和空气传播所造成的固定延迟仍需要硬件时钟、标定或外部测量补偿。
