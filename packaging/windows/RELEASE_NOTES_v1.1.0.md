# VoiceSpreader v1.1.0

此版本将桌面端迁移为原生 WinUI 3 界面，并保留现有多设备音频同步能力。

## 主要变化

- 支持浅色、深色及跟随 Windows 系统主题。
- 支持运行中实时调整各输出设备的相对补偿，包括输入、步进、滑杆和鼠标滚轮。
- 改进自动校准、校准中止和设备漂移跟踪，界面实时显示自动补偿结果。
- 优化单双栏响应式布局，按设备数量调整输出设备区和同步控制区的可见范围。
- 修复校准停止过程中可能卡住的问题。

## Windows 安装

本 Release 的 MSIX 使用项目自签名证书签署。首次安装前，请下载同一 Release 中的 `.cer` 文件并导入当前用户的“受信任人”证书存储区，再安装 `.msix`。详细命令见 `WINDOWS-INSTALL.md`。

私钥未上传到 GitHub。安装包仅支持 x64 Windows 10 2004（内部版本 19041）及以上系统。
